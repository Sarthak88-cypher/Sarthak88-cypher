# 💫 About Me:
I’m currently working on building scalable full-stack systems with a strong focus on Node.js backend architecture, distributed job orchestration, and frontend performance optimization using React and TypeScript. I’m looking to collaborate on high-impact product engineering projects, especially in areas involving microservices, event-driven systems, and AI-powered integrations. I’m also open to learning from experienced engineers in system design, advanced backend scalability, and enterprise-grade architecture patterns. At the moment, I’m actively deepening my understanding of Node.js concurrency, framework internals, and modern state management patterns like Redux and useReducer. Ask me about distributed systems, GraphQL APIs, performance optimization, or turning complex requirements into clean, maintainable production code. Fun fact: I genuinely enjoy debugging complex production issues — there’s something satisfying about tracing the root cause and making systems more reliable than before.
